## Reading

The marker-based zones do not correspond to the Ivy GAP anatomic structures on this section. This matches Glio-Cartography's earlier result on GSE237183 (diagonal mean 0.21, top-1 0.45) and is why the GBM pack stays in beta: it needs an annotated GBM reference and a domain model trained on independent labels before zone calls can be trusted.

Warnings raised by the pipeline:

- High mitochondrial fraction across the sample (median 28%); QC used an adaptive cut-off of 45%.
- No scRNA-seq reference supplied; using marker-score composition. This is not full deconvolution.
- Low agreement between deconvolution methods (mean 0.66); treat compositions as uncertain.
- Predicted zones correspond weakly to the external atlas (Ivy Glioblastoma Atlas Project (ISH)); zone labels are low-confidence.
