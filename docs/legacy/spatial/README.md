# Legacy spatial-transcriptomics product archive

The spatial application and its code remain in the repository for audit and historical reference. It is no longer the active product direction. Historical model cards, validation reports, and synthetic benchmark summaries are preserved under `validation/`.

All locally downloaded Visium/scRNA spatial source files and derived matrices were removed on 2026-11-07 to reclaim approximately 9.2 GB and prevent old assay data from being mistaken for the new perturbation-response benchmark. Source datasets can be re-downloaded from their original public repositories if the legacy workflow is revisited.
